# CRC Atlas Differential Expression and Annotation

This repository contains condition-specific differential-expression and cell-type annotation workflows for the colorectal cancer single-cell atlas.

## Current conditions

- [`adenoma/`](adenoma/) — complete Adenoma/Polyp workflow from original CCA pseudobulk DE through unresolved-cell refinement and final 1–29 cluster numbering.
- `crc/` — to be added.
- `normal/` — to be added.
